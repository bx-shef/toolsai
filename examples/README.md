# Примеры

Рабочие примеры к модулю. Не куски псевдокода: каждый файл запускается и сам
проверяет, что получилось именно обещанное. Разойдётся обещание с результатом —
пример падает с ненулевым кодом возврата, и это видит CI
(`tests/examples_test.php`).

## Что здесь есть

| пример | цель | где применять |
|---|---|---|
| [contract.php](contract.php) | контракт движка: GET 200, POST 202, колбэк `{"result": [...]}`, повтор задания | перед включением платного провайдера; при разборе «транскрипт не появился» |
| [quota.php](quota.php) | квота и цены из настроек -> микро-единицы -> остаток | настройка квоты; проверка квоты в своём модуле |

## Как запускать

Два режима, файлы одни и те же.

**Без портала** — ядро подменяется заглушками из `tests/stub/bitrix.php`,
классы модуля подключаются автозагрузкой из `tests/stub/autoload.php` по тому
же соглашению, что на портале. Так примеры гоняет CI:

```bash
php examples/contract.php
```

**На живом Битриксе** — подключается пролог, модуль берётся
`Loader::includeModule('shef.toolsai')`, классы находит автозагрузка:

```bash
DOCUMENT_ROOT=/var/www/portal php examples/contract.php
```

Режим печатается первой строкой: `Контракт движка: GET 200, POST 202, колбэк [портал]`.
Если там `[заглушки]`, а вы ждали портал — не нашёлся
`<DOCUMENT_ROOT>/bitrix/modules/main/include/prolog_before.php`.
